### Как воспроизвести пункты 15 и 16

Эти два состояния не достигаются штатными действиями на демо-наборе: мест 14 на 8 заявок, поэтому
дефицита не создать, а сдвинуть дату из интерфейса нельзя. Это известное замечание последнего
ревью — см. [docs/reviews.md](docs/reviews.md). Воспроизводятся через консоль браузера:

```js
// 15. Дефицит мест: заполнить все места и перераспределить
const s = JSON.parse(localStorage.getItem('ghost-relocation-bureau'))
s.bureau.ghosts = s.bureau.ghosts.map(g => ({ ...g, assignedLocationId: null, assignmentSource: null, assignmentRecord: null, status: 'pending' }))
s.bureau.locations = s.bureau.locations.map(l => ({ ...l, currentOccupancy: l.capacity }))
localStorage.setItem('ghost-relocation-bureau', JSON.stringify(s)); location.reload()
// затем нажать «Распределить автоматически»
```

```js
// 16. Размещение с истёкшим сроком: сначала распределить, затем сдвинуть дедлайн в прошлое
const s = JSON.parse(localStorage.getItem('ghost-relocation-bureau'))
s.bureau.ghosts.find(g => g.id === 'g-vivian').deadline = '2026-01-01'
localStorage.setItem('ghost-relocation-bureau', JSON.stringify(s)); location.reload()
```

## Что осталось непроверенным

Честно, чтобы не создавать впечатление полного покрытия:

- **Переполнение квоты localStorage при записи.** Код обрабатывает отказ (`saveState` возвращает
  сообщение, оператор видит предупреждение), но искусственно квоту не переполняли.
- **Мобильные браузеры.** Вёрстка проверена эмуляцией 375 × 812 — горизонтального переполнения нет,
  но на реальных устройствах не запускалась. Инструмент рассчитан на десктоп.
- **Скринридеры.** Роли, `aria-selected`, `aria-controls` и клавиатурная навигация проверены
  в DOM и тестами; с реальным NVDA / VoiceOver приложение не тестировалось.
