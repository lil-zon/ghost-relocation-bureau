# Финальный аудит

Проверка не по наличию кода, а по фактическому поведению. Отметка «проверено» означает, что
поведение подтверждено автоматическим тестом либо запуском приложения в браузере (или тем и другим).

Прогон верификации на момент аудита: `npm run typecheck` — без ошибок, `npm run lint` — 0 ошибок и
предупреждений, `npm run test` — 73 теста в 7 файлах пройдены, `npm run build` — сборка успешна.

## Доменные инварианты

| Инвариант | Проверено | Чем |
| --- | --- | --- |
| Блокирующий конфликт нельзя компенсировать баллом | да | тест: у несовместимого места `score === 0` при `breakdown.total === 100` |
| Занятость никогда не превышает вместимость | да | тест последовательных назначений + `assertCapacityInvariant` |
| Просроченная заявка не назначается никуда | да | тест с `confirmed: true` — назначение всё равно отклонено |
| Ручное и автоматическое назначение проходят одну проверку | да | обе ветки вызывают `validateAssignment` внутри `assign()` |
| Назначение с предупреждениями требует подтверждения | да | тест: без `confirmed` — отказ, с `confirmed` — успех |
| Распределение детерминировано | да | тест: повторный прогон даёт тот же результат |
| Автоматический прогон не переписывает ручные решения | да | тест: ручное назначение сохранено, помечено `skippedManual` |
| Заявка не блокирует сама себя на своём же месте | да | тест повторной проверки собственного места при полной занятости |

## Состояния интерфейса

| Состояние | Проверено | Как |
| --- | --- | --- |
| Empty state | да | кнопка «Очистить» → сообщение и загрузка демо-данных (браузер + тест) |
| No match | да | Инженер Кальцифер: «Ни одно из 6 мест…», список блокировок по местам |
| Location full | да | Особняк Тумановых: «заполнено», выбор в ручном режиме запрещён |
| Manual conflict | да | выбор заполненного места: «Назначение запрещено», причина и серьёзность |
| Подтверждение при замечаниях | да | Городской театр для Агаты: двухшаговое подтверждение (тест) |
| Generic error | да | испорченный localStorage → «Сохранённые данные бюро повреждены…» и показ демо |
| Ошибка рендеринга | да | ErrorBoundary непреднамеренно сработал во время рефакторинга: при горячей замене модулей возник `ReferenceError: plural is not defined` в `ManualAssign`, граница перехватила его и показала сообщение вместо белого экрана. После перезагрузки ошибка не воспроизводится |

## Демонстрационные сценарии

Все двенадцать требуемых сценариев присутствуют в наборе и наблюдаемы в приложении: обычный
успешный подбор, высокая тревожность, требование влажности, несколько особых условий, просроченный
срок, отсутствие подходящего места, полная занятость, ручной конфликт, конкуренция за одно место,
место с людьми, шумное место и слишком светлое место. Дополнительно — закрытое на ремонт место.
